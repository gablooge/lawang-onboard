# Bob sessions

Evidence of IBM Bob IDE usage, required by the hackathon: a screenshot of the session consumption
summary of **every** Bob task related to this project.

How: in Bob IDE chat open **Tasks**, select the task, click the task header to show the session
consumption summary, screenshot it as PNG.

Naming: `lawangonboard_task##_<short_description>_summary.png`, two-digit task number, snake_case,
for example `lawangonboard_task01_setup_check_summary.png`. An exported task history, when there
is one, sits next to it with the same name and `.md`.

Every screenshot has a row in [LEDGER.md](LEDGER.md).
